## 1. 总体原则

- 使用目标国家对应语言：美国为美式英语、加拿大为加拿大英语、墨西哥为墨西哥西班牙语。表达自然、清晰、具体，不做夸张推销。
- 事实准确性 > 可读性 > 关键词覆盖率。只写 `01_product_profile.json` 中已确认的事实。
- 禁止促销、价格、配送承诺、排名、极限词、竞品对比、未授权品牌与无法证实的性能/认证声明。
- 避免关键词堆砌：同一完整目标短语不在同一字段重复；标题中有意义的内容词尽量只出现一次。冠词、介词等语法词不按堆砌词计算。
- 不为了塞词破坏语法，不把被过滤词换写后重新使用。

## 2. Product Title

硬规则：

- 50–75 个 Unicode 字符，包含空格和标点。
- 清晰、具体、可读；US/CA 使用自然英文标题大小写，MX 使用自然西班牙语句式大小写，保留品牌/型号的官方写法，不把每个西班牙语词强制首字母大写。
- 用户提供授权品牌时以品牌开头；未提供品牌时以商品名称开头。
- 推荐结构：`Brand + Product Name + Style + Primary Attribute`。
- 只使用与真实商品一致的关键词；优先使用 `05_keyword_plan.json.title` 中靠前的 1–2 个短语。
- 不重复核心内容词，不连续堆同义品类词，不写促销和主观极限词。

生成后精确计数。少于 50 字符时加入最重要且真实的款式/材质/规格；超过 75 字符时按低优先级属性逆序移到描述或 Key Features，不得硬截断单词。

## 3. Product Description

硬规则：

- 第一行或第一段开头逐字放入最终 Product Title。
- 至少包含一个不少于 150 个目标语言单词（US/CA 为英语，MX 为西班牙语）的实质性段落；标题本身不计入 150 词。
- 说明材质、结构、规格、功能、使用场景、限制、护理/使用建议和真实变体；没有的维度不补写。
- 语气清楚、坦诚、非正式但可信，目标是提供决策信息，而不是强行推销。
- 有变体时列出所有用户已确认的颜色、尺码、风格、数量等选项。
- 自然承接标题和 Key Features 未覆盖的高价值关键词、同义词与长尾词；每个完整目标短语最多自然出现一次。
- 不使用竞品事实，不添加“联系我们”“保证满意”等未确认售后承诺。

描述可为多段，但不得用冗长空话凑 150 词。未知护理方式、适配性或性能参数不写。

## 4. Key Features

硬规则：

- 3–10 条，按重要性降序。
- 每条最多 80 个 Unicode 字符（含空格）。
- 采用短语或简洁要点，不要求完整句；每条聚焦一个优势、功能或明确规格。
- 使用事实导向格式，例如 `Upper Material: Genuine Sheepskin Leather`。
- 可以自然嵌入分配词，但不能写成逗号分隔的关键词串。

避免 Amazon 风格的长句、全大写营销标签和重复结论。

## 5. 变体标题

默认生成父体标题。只有用户提供真实变体时，额外给出：

```text
<Parent Title> (<Color>, <Size/Quantity>)
```

按实际字段调整括号内容。每个子体标题也要控制在 50–75 字符；若追加变体会超长，先缩短父体中的低优先级属性，再生成模板。不得编造颜色或尺码。将用户已提供组合逐一展开到 variant_titles 供本地检查，不自动生成颜色×尺码组合。

## 6. 关键词分配与覆盖

Walmart 本流程不输出后台 Search Terms。按优先级分配：

1. Title：最高价值品类短语与关键属性，1–2 个完整短语即可。
2. Key Features：与具体材质、功能、规格或场景相匹配的属性词。
3. Product Description：其余热门泛词、同义词和自然长尾词。

优先真实热搜信号和多竞品共同命中词，减少冷门长尾。不得要求“所有词必须覆盖”；因可读性、重复、事实不足或合规风险放弃的词必须写入 `not_planned` 或 `08_keyword_coverage.json`。

仅使用 eligible 词池；deferred/excluded 不进入任一文案或图片文字，事实未确认时不能通过改写绕过。声明依据记录在 JSON 的 claims，审核元数据不进入上架正文。

覆盖审计采用不区分大小写的完整短语匹配，允许连字符与普通空格的等价规范化，但不把语义近似当成命中。

## 7. 图片策划

仅输出中文策划，不直接生成图片。按用户提供图片数量和商品特征规划：

- 图1主图：清晰呈现真实商品、数量和结构，不加入未经确认配件。
- 副图：依次覆盖核心功能、真实尺寸/材质、使用场景、变体与包装清单。
- 图片文字必须与 Listing 事实一致；不得写极限词、竞品对比或未验证声明。

若用户未提供足够图片，给出建议拍摄清单，并明确哪些画面需要补拍。

## 本地语言复核（不改变原有长度和字段规则）

- CA：加拿大英语；普通文案采用 colour、odour、litre 等加拿大拼写，品牌或型号原文保持不变。使用来源明确的 mL/L 等规格，不因套用US模板自动转换单位。不要将加拿大英语要求误写成法语或双语要求。
- MX：自然墨西哥西班牙语；按语境使用 contenedor、refrigerador、lonchera 等当地常用词，保持重音和 ñ，品牌/型号可保留原语。标题用自然句式大小写；数字与单位保持准确，不将1.65 L误写成165 L。
- 三站都逐项核对标题、正文、Key Features、变体标题与图片叠字；不能仅修改 listing_language 标签。copy_checks 的语言信号只检测正文是否明显错标，CA拼写提醒不是词语禁用表。品牌保留、短句与地区表达仍需语义复核，不能因机器检查通过就宣称本地化全部正确。
